## How to use 

1. Copy or download the Python code
2. Import the required libraries 
3. Run it in VS Code or any similar IDE
4. Upload the folder. All the files with their respective JSON files will be sorted according to the file name. 
5. Select to merge a single photo or merge all.
6. The data will be directly reflected in the image properties.
7. You can delete the JSON files directly from the app itself.
